Ticketing System for a Performance Hall

  • Developed a role-based ticketing system using Java, enabling admin CRUD operations for events and stock, and customer workflows for purchasing and checkout.
  • Implemented event browsing, ID-based search, and language filtering using Swing components, event listeners, and MVC-style structuring to improve user navigation.
  • Integrated secure payment options (PayPal, Credit Card) with real-time stock synchronisation using BufferedReader, BufferedWriter, file I/O streams, and custom toString() overrides for receipt generation.
  • Applied core OOP principles — encapsulation, inheritance, interfaces, enums — and utilised Java collections, exception handling, and modular class design to ensure scalability and maintainability.

I built a role-based ticketing system in Java as part of my coursework at Loughborough University. The project aimed to simulate a real-world ticketing system for a performance hall, allowing users to purchase and manage tickets for events.

I began by designing the system using OOP principles to create a role-based ticketing system. I implemented a comprehensive event browsing, ID-based search, and language filtering using Swing components, event listeners, and MVC-style structuring to improve user navigation. This feature allowed users to easily find and purchase tickets for the events they wanted.

To manage the inventory, I used Java's data structures and file handling capabilities. I implemented secure payment options using BufferedReader, BufferedWriter, file I/O streams, and custom toString() overrides for receipt generation. This helped store managers keep track of the stock and ensure that popular items were always available.
